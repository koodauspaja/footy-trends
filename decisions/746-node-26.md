# 746 — Node.js 26: decisions

Chore #746, on Renovate's #741. Node 26 became LTS ('Lithium') on 2026-10-28,
with support until April 2029; the repository was on 24. #741 moved `.nvmrc`,
every workflow's `node-version` and `@types/node`. This finishes it.

| Decision | Why |
|---|---|
| Every environment moves at once: local, CI and Railway | They read the same `.nvmrc`. Railway's builder, Railpack, takes the version from it: production's build log on 2026-10-30 lists `node │ 24.22.1 │ idiomatic-version-file`. One file keeps them from drifting apart |
| `engines.node` is `>=26` | It said `>=24`, which would accept a Node the suites no longer run on |
| `docs/infrastructure.md` records where the web service's Node comes from | Nothing said it, and the answer decides whether a Node change reaches production |
| `.nvmrc` stays out of the web service's watch patterns | A push changing only `.nvmrc` deploys nothing. #741 also changes `package.json`, which is watched, so it deploys. Adding the file is a change to `.railway/railway.ts` and an apply per environment, outside this chore |
| `tests/unit/scripts/setup-shell.test.ts` keeps `nvmrc = "24"` | It is a fixture the setup script's tests write into a temporary clone, not the repository's version |

| No `libatomic` step of our own | Node's notes say its Linux binaries link against `libatomic` since 25. Railpack installs `libatomic1` itself: the build log of a Railway environment from this branch, `node26`, lists `install apt packages: libatomic1` |

Verified on Node 26.13.0 with npm 12.2.1: lint and typecheck clean; unit 6 134

On Railway, 2026-10-30: `node26`, built from this branch by

the branch's commit. The environment was deleted after.
