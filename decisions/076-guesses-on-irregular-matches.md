# 076 — Arvauspeli: matches that do not go as listed: decisions

Feature #760, `specs/076-guesses-on-irregular-matches.md`. Guesses on a
Veikkausliiga match that is postponed, abandoned, awarded, or moved earlier are
settled by rules of their own. Builds on decisions/072, and is released with it.

| Decision | Why |
|---|---|
| TASO's own status is stored beside the normalized one, `taso_matches.provider_status`, migration `0022_add_taso_provider_status`. `status` still folds `Forfeited` into `FINISHED`, so tables, simulations and predictions read what they read before. A row stored before has null there, and reads as played | The spec's data. Named after the column, not the spec's working name `add_taso_raw_status`. A null `provider_status` is a row no refresh has rewritten since; in Veikkausliiga that is only past seasons, which no guess reaches |
| The e2e fixture recorder sends a match's stored TASO status back as TASO sent it, and maps the normalized one only for a row with none | A walkover recorded as `Played` would replay as a played match, and the stand-in could never serve an awarded one |
| A match TASO has decided before its kickoff, `FINISHED` (a walkover's `Forfeited` included) or `Abandoned`, is closed to guesses and left out of `Tulevat ottelut`, by one rule, `guessPrice`, which the page and a guess share; a guess sent anyway is refused as `started` | From review: a walkover known before its kickoff would have left score guesses open to a sure 100. Miikka, 2026-11-05: "agreed on those choices". Any other status keeps a match open, so a postponed one stays guessable whatever TASO calls it (S5) |
| Rows stored before `provider_status` get it from `npm run backfill -- --refetch`, run in each environment once the migration has deployed | `docs/infrastructure.md`'s rule for a new column on stored matches; until then such a row reads as played, which only past seasons are |
| Each guess stores the kickoff it was last made or changed against, `game_guess.kickoff_at`, migration `0023_alter_game_guess_for_settlements`. The migration fills it for any guess already stored from its match's kickoff, or its own time for a guess whose match is gone, before making it `NOT NULL` | S5. The refresh overwrites `kickoff_at`, so the guess has to keep the kickoff it was made against. Hand-edited from what `drizzle-kit` generated, which added the column `NOT NULL` at once and would fail on a database holding guesses |
| A stored kickoff later than the guess's is a postponement: the next change is free, a change row of `0`, the floor's free guess included, and it records the new kickoff, so a second free change needs a second move. A new guess on a postponed match is priced by the new kickoff | S1, S5. "Once per postponement" falls out of the stored kickoff moving on with the change, so two moves before one change give one free change. Miikka, 2026-11-05: "agreed on those choices" |
| The floor's free guess takes a postponement's free change as a 1X2 only, and its form offers no score; a score is refused as `free-fixed` | S5 includes the floor's guess, and 072 makes that guess a free 1X2. Changed to a score for free, it would be a free guess worth up to 100 that the floor never gives. Miikka, 2026-11-05: "agreed on those choices" |
| The page marks such a row: "Ottelu siirtyi. Voit muuttaa arvaustasi kerran maksutta." above it, and "Muutos on maksuton" where the price stands; it sends `0` as the price shown (072's S26) | The spec's strings. The spec names the second the change button; it stands where the price line stands, as "Muutos maksaa {price}" does, and the button stays `Muuta arvausta` (072's S20) |
| Settling reads every open guess whose match has kicked off, and every one whose match is no longer stored, and decides each with `settlementOf`: a guess made at or after the stored kickoff is void; an abandoned match is refunded; an awarded one, TASO's `Forfeited`, pays every score guess 100 and a 1X2 by the awarded score or TASO's `winner`, and with neither is refunded; a played one pays by 072's tiers; anything else waits | S2, S3, S4, S9. Void comes first: a guess made after a kickoff that moved earlier is refunded whatever the match then did |
| A refund pays back everything paid on the guess, its guess row and its changes, as a `refund` row. The ledger's one-reward-per-guess index becomes one settlement per guess, a reward or a refund | S2. The index is what keeps a retry from paying twice (decisions/072) |
| `game_guess.tier` holds how the guess was settled: 072's four tiers, or `awarded`, `abandoned`, `undecided` or `void`. A refund, and an award with no score, store no result | One column read the same way for every settlement |
| `Ratkaistut` says `Ottelu ratkaistiin päätöksellä +{n}`, `Ottelu keskeytettiin, pelimerkit palautettu +{n}`, `Ottelua ei ratkaistu, pelimerkit palautettu +{n}` or `Arvaus tehtiin ottelun alettua, pelimerkit palautettu +{n}`, and a guess with no stored result shows its teams with no score | The spec's strings |
| A guess whose match is no longer stored still counts as open, for the floor, and is not listed, having nothing to name; settling leaves it open | S8. Before, the join dropped it, and with it the floor's "open guess" |
| Settling names a match whose guesses still wait at `warn`, once per match and run, `Arvauspeli guesses still waiting`, with its id, status, kickoff and why: `not stored`, `unknown status` (other than `FINISHED` and `SCHEDULED`: of the statuses Measured lists for Veikkausliiga, the rest is `Abandoned`, which is refunded and never waits), or `no result` 48 hours or more after kickoff | S7, S8, S10 |
| The run's summary counts refunded and voided guesses beside rewarded and missed, and its `Settled` line counts all four | The spec's Logging |
| Not built: a match postponed with no new date, and a cancelled one | S6 to S8. Never seen for Veikkausliiga; the `warn` names the first case |
| Tests: unit for every branch of `settlementOf`, the free change after a postponement, the store's refunds, voids, awards and waits, the warnings, and TASO's own status; integration for an abandoned match's full refund, an awarded match, a moved-earlier kickoff, one free change and no second, and the stored status | Spec, Tests Required |
