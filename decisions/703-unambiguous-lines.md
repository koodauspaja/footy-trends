# 703 — A match page's title, its meetings line and an average position read unambiguously: decisions

Chore #703, three lines the #695 sweep found working against each other. Each
string was agreed with Miikka on 2026-10-23, and is written on the issue.

| Decision | Why |
|---|---|
| A match page's `h1` is its scoreboard: `IF Gnistan 2–1 AC Oulu`, each name a link to its team page where it has one, and `IF Gnistan – AC Oulu` before the match. The line that repeated it under the heading is gone. The tab title is unchanged: `VPS – FC Lahti, Veikkausliiga 2026` | The page named its teams twice, once as a heading and once as a scoreboard. This overrides decisions/019's "The scoreline puts the names either side of the score", which kept the scoreboard as a line of its own for the links a heading string could not carry. `PageShell` takes a heading that is not plain text for it, and the other pages pass strings as before. `specs/019-match-page.md`'s heading and empty line now say the same |
| A level score with a declared winner, a TASO cup tie settled on penalties it never itemises (decisions/019, `declaredWinnerSide`), keeps the winner at the heading's weight and drops the loser to normal. Every other score leaves both names at the heading's weight | The old scoreboard set that winner semibold against a normal-weight loser, and both names normal otherwise, because any other score already says who won. Inside a semibold heading the same distinction needs the loser set to normal, not the winner set to bold. `specs/019-match-page.md`'s Score section and edge case now say so |
| `Aiemmat kohtaamiset`'s empty line: `Ei kohtaamisia ennen tätä ottelua.` The link `Kaikki kohtaamiset (4)` is unchanged | `Aiempia kohtaamisia ei löytynyt.` directly above `Kaikki kohtaamiset (4)` read as a contradiction, since the four include later meetings. The line now says it means before this match |
| An average position has no ordinal period: `1,7`. A place keeps it: `9.`. The text alternative reads `Sijoitus: tämä kausi 9., tavallisesti 1,7.` | `1,7.` read as an ordinal after a decimal. This overrides decisions/038's `5,8.` for the baseline, and its "The text alternative's full stop" row: the sentence's own full stop now always follows the baseline, which never ends in one, so the suppression is gone |
